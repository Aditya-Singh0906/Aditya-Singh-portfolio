# Aditya Singh - DevOps & Cloud Portfolio

A premium, production-ready, SaaS-style Command Center portfolio for **Aditya Singh**, DevOps & Cloud Engineer.

## 🚀 Key Features

* **Command Palette (Ctrl + K / slash key)**: Global search across projects, blogs, skills, and operations triggers.
* **8 Interactive DevOps Visualizations**:
  * AWS Network Topology (VPC, Subnets, ALBs, S3, IAM)
  * Kubernetes replica scale simulation (spawning/terminating pod nodes)
  * Multi-Stage Docker image layer shrink visualizer
  * Terraform resource dependency graph (HCL blocks)
  * Jenkins Pipeline-as-Code horizontal compiler
  * GitHub Actions parallel jobs triggers
  * End-to-end Git-to-Cluster CD flow mappings
  * Grafana metrics monitoring panel with spike alerts
* **Dynamic GitHub Stats**: Automated repository metadata fetches with fallback indicators.
* **Premium SaaS UX/UI**: Dark mode first layout, glassmorphic grids, custom cursor dynamics, and smooth transitions.
* **WCAG AA Compliant**: Accessible Radix primitives, keyboard-navigable dialogs, and semantic markup layouts.

## 🛠️ Tech Stack

* **Core**: Next.js 15 (App Router), React 19, TypeScript
* **Styling**: Tailwind CSS v4, Lucide Icons
* **Animation**: Framer Motion
* **Primitives**: Radix UI
* **SEO**: Static sitemaps, robots tags, person schema markup, RSS feed syndication
